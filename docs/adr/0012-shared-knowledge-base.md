# 最小 MVP 通过成员引用读取同步资料

> 参考状态（2026-10-06）：本文记录此前产品方向下的技术决定，保留供新场景评估。文中的 accepted 表示当时的决定状态，不代表新产品已采用全部约束。当前产品定义见 [兴趣小组场景与产品定义](../product-design/product-definition.md)。

2026-10-05 确定先交付一个最小 MVP：用户在自己的工作 Agent 中通过 `@` 选择成员，读取该成员同步到共享空间的资料，由提问方自己的 Agent 生成有来源的回答。服务先实现身份、成员选择接入、资料同步、检索、版本和撤回，以一条实际工作流程验证资料的价值。

本决定仅确定当前阶段的实现范围。完整 PRD、领域模型及 ADR-0001 至 ADR-0011 保留，响应 Agent、模型服务、额度和自动整理等设计不作为当前 MVP 的实施前置。本阶段不执行 ADR-0010 的在线响应及会话自动求助部分，也不执行 ADR-0011 的候选回答重新生成部分；资料撤回对后续读取生效，已经取得的副本由使用方环境管理。

本阶段共享空间保存成员主动提供的资料，按提供成员限定检索；用户输入 `@` 后的真实成员列表和稳定成员引用必须经过宿主验证。具体范围见 [最小 MVP](../archive/2026-10-06-product-direction/docs/product-design/minimal-mvp.md)。
