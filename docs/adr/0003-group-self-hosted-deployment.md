# 由各团队或群组自行部署项目

首版面向能维护服务器的群组管理员，提供安装、配置、更新与备份恢复文档，普通成员通过桌面应用和工作 Agent 接入。

2026-10-04 确定 oh-share-it 作为供有需要的团队或群组自行部署的项目交付。群组部署方管理服务、授权资料副本与运行费用，成员无需分别部署在线响应器；项目的技术选择优先支持群组自行安装、配置、升级和备份。首版一次部署只服务一个群组，各群组分别部署，成员身份、管理员权限、通信记录与授权资料在各自部署范围内管理，以简化群组安装配置与权限管理。模型账户由管理员配置，成员从管理员提供的可用模型列表选择响应模型，未设置时使用群组默认模型。成员额度累计实际总 Token 并按月分配，管理员可调整与补充。跨部署连接与互联能力留待后续，具体部署配置在工程设计中确定。
