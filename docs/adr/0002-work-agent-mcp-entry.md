# 通过已有工作 Agent 的 MCP 接入提供求助能力

> 参考状态（2026-10-06）：本文记录此前产品方向下的技术决定，保留供新场景评估。文中的 accepted 表示当时的决定状态，不代表新产品已采用全部约束。当前产品定义见 [兴趣小组场景与产品定义](../product-design/product-definition.md)。

2026-10-04 确定成员已有的工作 Agent 是发起求助与使用回答的主要产品入口，首版以群组部署的远程 MCP 服务器提供产品能力，Skill 为可选使用指导，不提供 CLI。成员希望在原有工作流程中直接求助，MCP 可以复用不同宿主的标准工具接入；CLI 增加安装与配置操作，产品专用插件需要分别维护。桌面应用继续负责分享资料同步与配置，查看界面负责上下文审查和共享内容阅读；回答由成员授权的群组部署环境中的在线响应器处理，不要求其工作 Agent 同时在线。远程入口通过 HTTPS 上的 Streamable HTTP 提供调用，成员无需安装本地 MCP 程序；采用 OAuth 浏览器登录授权连接该部署中的成员账户，减少手动复制和维护访问令牌的操作；具体授权服务实现另行选择。
