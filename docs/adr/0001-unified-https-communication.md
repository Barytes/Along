# 求助与回答统一经过群组 HTTPS 服务

> 参考状态（2026-10-06）：本文记录此前产品方向下的技术决定，保留供新场景评估。文中的 accepted 表示当时的决定状态，不代表新产品已采用全部约束。当前产品定义见 [兴趣小组场景与产品定义](../product-design/product-definition.md)。

群组自行部署的服务统一运行在线响应器并保存成员授权资料副本，并需要统一管理成员身份、定向记录权限、异步请求状态和群组通信监督。2026-10-04 确定通过产品提交的求助与回答统一经过群组 HTTPS 服务，以便这些管理规则在同一通信路径执行。邮件、请求文件与成员直接互联保留为方案比较；数据库与部署环境分别选择；工作 Agent 的接入决定见 [ADR-0002](./0002-work-agent-mcp-entry.md)。
