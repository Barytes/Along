# 群组业务状态使用 SQLite，资料副本使用持久文件目录

> 参考状态（2026-10-06）：本文记录此前产品方向下的技术决定，保留供新场景评估。文中的 accepted 表示当时的决定状态，不代表新产品已采用全部约束。当前产品定义见 [兴趣小组场景与产品定义](../product-design/product-definition.md)。

2026-10-04 确定首版群组业务服务使用 SQLite 保存成员、请求状态、回答、额度记录及资料元信息，授权资料正文副本保存在服务器持久文件目录。单群组部署起点优先减少独立数据库服务，相较于部署 PostgreSQL，管理员维护的组件更少。数据库与资料目录需要共同备份恢复，模型网关的内部存储要求另行核对；未来多个应用节点或较多并发写入时重新评估业务数据库。
