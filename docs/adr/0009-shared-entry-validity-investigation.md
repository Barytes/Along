# 共享条目排查后保留有效内容并删除无法确认有效的内容

> 参考状态（2026-10-06）：本文记录此前产品方向下的技术决定，保留供新场景评估。文中的 accepted 表示当时的决定状态，不代表新产品已采用全部约束。当前产品定义见 [兴趣小组场景与产品定义](../product-design/product-definition.md)。

共享条目收到错误或失效反馈后，由群组整理 Agent 协调提供方 Agent，在既有授权、群组整理额度及提供方响应上限内排查。确认有效或修订后有效则保留，到达排查期限或额度上限仍无法确认有效则删除正文、专属依据副本和历史正文，只保留最小处理记录。该选择避免共享空间长期保存无法确认有效的条目；后续获得充分依据时可以重新收录，原始交流及其他有效条目仍使用的依据遵守各自保留规则。
