# 本次 MVP 交付成员选择、目录同步与会话自动求助

> 参考状态（2026-10-06）：本文记录此前产品方向下的技术决定，保留供新场景评估。文中的 accepted 表示当时的决定状态，不代表新产品已采用全部约束。当前产品定义见 [兴趣小组场景与产品定义](../product-design/product-definition.md)。

2026-10-05 为验证群组成员已有资料能否帮助其他成员完成当前工作，确定本次 MVP 采用指定目录自动同步，跟随资料新增、修改和删除，保留成员对分享范围的控制。采用成员独立授权副本与在线响应，优先验证产品价值与 Agent 应用工程能力；资料集中保存不自动授予全组浏览或下载原文的权限。[ADR-0004](./0004-hybrid-online-local-response.md) 的本地响应与混合调度留待后续。资料处理涉及部署方与配置的模型服务，其具体保留及管理访问规则继续澄清。

本次同步成员明确选定的可分享文件，通过目录、文件格式及文件或子目录排除规则确定范围。成员负责将适合分享的文件纳入范围，系统自动同步范围内的变更；内容筛选可以辅助检查，但不自行扩大授权。包含私人内容的混合资料自动提取、脱敏及候选副本确认留待后续，以减少本次资料接入的实施与维护工作。

用户在已有工作 Agent 中输入 `@` 时必须出现群组成员列表，选择成员后形成明确的成员引用并发起求助；文本中直接写出姓名不替代成员选择交互。远程 MCP 继续承担业务调用，宿主成员列表的接入机制及首批支持宿主尚待验证和确定。

用户主动调用求助 Skill 即授予工作 Agent 当前会话内的自动求助权限，可以在既有分享范围与资源额度内自行发现信息缺口、选择成员并提问；该授权不自动延续到其他会话。以主动调用 Skill 表达成员的会话选择，避免为每次求助重复配置，同时保留成员对何时自动求助的控制。

问题可以附带当前任务所需的文件片段或会话片段，全部发出内容遵守发起方预设的分享规则，授权无法明确判断时由发起方确认。会话授权的记录与撤销、背景分享检查及单次任务限制继续澄清；Skill 不替代成员身份、资料权限与额度的产品执行。
