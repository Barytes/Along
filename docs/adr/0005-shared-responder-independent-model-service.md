# 共用在线响应服务与独立模型服务

> 参考状态（2026-10-06）：本文记录此前产品方向下的技术决定，保留供新场景评估。文中的 accepted 表示当时的决定状态，不代表新产品已采用全部约束。当前产品定义见 [兴趣小组场景与产品定义](../product-design/product-definition.md)。

2026-10-04 确定首版共用群组在线响应服务，每位成员分别配置资料授权、模型、回答策略与资源上限，每次请求创建独立执行上下文。相较于为每位成员维护独立服务，当前成员差异以配置表达，减少服务创建、升级和运行状态管理工作。

模型调用由独立模型服务提供，在线响应器与桌面本地响应器共同调用，群组业务服务负责求助状态、资料授权与消耗归属。该组织方式支持桌面应用直接使用群组模型账户，并集中管理提供商凭据与用量。首版模型调用限于产品内求助响应，具体调用授权、额度执行及网关产品继续确定。
