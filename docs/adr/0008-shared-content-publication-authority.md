# 共享内容的整理与发布授权分别管理

> 参考状态（2026-10-06）：本文记录此前产品方向下的技术决定，保留供新场景评估。文中的 accepted 表示当时的决定状态，不代表新产品已采用全部约束。当前产品定义见 [兴趣小组场景与产品定义](../product-design/product-definition.md)。

群组整理 Agent 可以从获准的定向求助记录、留言板及已有共享内容中发现重复需求并整理可复用解答，但读取权限不授予全组发布权限。候选条目分别遵守各内容提供者的分享规则，预先允许向全组分享的内容自动发布，授权不明确时展示具体条目并请求确认。该选择让重复求助能够转化为共享内容，同时保留成员对信息接收范围的控制；求助频率和群组收录规则均不能代替内容提供者的发布授权。
