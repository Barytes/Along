# 撤回资料后清理副本并按当前授权重新回答

> 参考状态（2026-10-06）：本文记录此前产品方向下的技术决定，保留供新场景评估。文中的 accepted 表示当时的决定状态，不代表新产品已采用全部约束。当前产品定义见 [兴趣小组场景与产品定义](../product-design/product-definition.md)。

2026-10-05 确定成员删除、排除或撤回资料后，服务先停止后续使用并阻止仍依赖该资料的候选回答提供，再清理在线正文副本、检索索引和资料摘要，只保留资料标识、撤回时间及处理状态等必要记录。撤回生效与内容清理完成分别展示。选择清理内容，使成员结束资料授权后，服务结束对该资料的持续保存；备份清理规则及具体清理时限继续确定。

失效候选回答默认在同一次请求的剩余额度与等待期限内，使用当前获准资料重新检索、生成并检查，资料不足时明确返回依据不足。该选择让求助在当前授权下继续完成，不默认要求成员重新授权被撤回的资料；自动重新生成次数及额度或期限耗尽时的结果继续确定。

已经提供的定向请求、回答及获准引用按群组统一配置的期限保留，到期清理正文和引用，可以保留不含正文的请求状态与用量记录。原始资料撤回不自动删除已提供回答，使资料使用授权与已获准交流的保留各自明确。具体保留期限继续确定；已发布共享内容继续遵守独立的发布与撤回规则。
