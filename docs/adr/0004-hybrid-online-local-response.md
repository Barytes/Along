# 在线资料副本与本地响应器并存

2026-10-04 确定采用混合响应策略：在线响应器依据成员授权同步的资料副本提供及时回答，本地响应器访问成员保留在本机、未同步到群组服务的获准资料。成员无需为支持某类求助而上传全部原始资料，例如可以在本地查询通讯录并仅提供获准回答；资料访问与回答分享遵守成员授权。两条路径仍通过群组 HTTPS 服务关联请求与结果，响应路径按成员预设的本地查询范围选择，其余请求优先使用在线副本；需要本地查询而本地不可用时保留待处理状态。本地响应器由桌面应用运行，默认调用云端模型处理获准资料并按成员分享规则生成答案。在线与本地响应器使用管理员配置的模型账户，调用消耗归属于求助者。模型调用经过独立模型服务，首版本地资料来源为成员指定、未同步的目录，本地支持目录列出、搜索、读取和 PDF／Office 转 Markdown 工具，暂不支持图像理解及 OCR。自动回答使用明确获准分享的资料范围，尚未明确授权分享的提炼内容由资料所属成员确认后发送。求助者配置自己发出请求的默认等待时间，提交时保存截止时间，具体模型调用授权在工程设计中确定。
