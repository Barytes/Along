# Along

Along 由团队或群组自行部署，让固定群组中的成员通过各自的 agent 获取彼此已有的资料、信息和经验。成员控制个人资料的使用与分享，群组共同管理已发布的交流和共享内容。

完整产品领域词汇如下。本次最小 MVP 使用其中的成员、成员引用和资料来源概念，具体交付范围见 [最小 MVP](docs/product-design/minimal-mvp.md)。

## Language

**成员**：
加入群组、拥有个人资料并决定其使用与分享规则的人。同一成员可以使用多个 agent，成员身份不随 agent 的更换而改变。
_Avoid_: 将成员与某个 agent 等同

**成员引用**：
在工作对话中明确指向某一群组成员的引用，由用户从群组成员列表中选择形成。成员引用指向成员身份，不因显示名称或回答 agent 的变化而改变。
_Avoid_: 将成员引用与普通姓名文本或某个 agent 会话等同

**群组**：
由相互认识、通过邀请加入的成员组成的持续协作小组。群组的成员资格和共同内容遵守该群组的管理规则。

**个人资料**：
由成员自行管理、用于其个人工作或积累的资料，包括本人记录和个人收藏。个人资料只有在成员授权的范围内才能用于向其他成员回答问题。
_Avoid_: 将个人资料与群组共享空间等同

**分享范围**：
成员允许向指定群组或成员提供的信息范围，适用于发出的求助背景和提供的回答。允许本人使用某份资料，不等于允许向群组分享该资料。

**分享规则**：
成员规定哪些内容可以向队友提供、哪些内容不得提供，以及何时需要本人确认的规则。分享偏好或分享 Skill 可以表达这些规则，规则仍受成员既有分享范围约束。

**本地查询目录**：
成员指定供本地响应器查询、未同步为在线资料副本的目录。目录中的资料可以用于获准的回答处理，向队友提供的内容遵守成员分享规则。
_Avoid_: 将本地查询目录与同步的分享资料目录等同

**授权资料副本**：
经成员授权复制、供其响应 agent 使用的个人资料副本。副本仍受成员的分享范围约束，保存副本不等于向群组发布其中的资料。
_Avoid_: 将授权资料副本与共享空间等同

**授权资料撤回**：
成员结束某项个人资料被响应 agent 持续使用的授权，适用于资料删除、移出分享范围或主动撤销授权。资料撤回与已经提供的回答、已经发布的共享内容具有各自的保留和撤回规则。
_Avoid_: 将资料撤回与所有历史回答或共享内容的自动删除等同

**分享资料目录**：
成员指定用于持续提供分享资料的本地目录，目录内符合筛选规则的文件决定授权资料副本的内容与范围。在线副本以该目录为权威来源，文件删除或移出获准范围后应撤回在线使用。
_Avoid_: 将在线副本视为独立维护的资料库

**成员介绍**：
成员向群组公开、用于发现合适求助对象的信息，分别描述关注主题、当前可提供的信息和近期回答过的主题。当前可提供的信息以仍可访问且获准分享的资料为依据。
_Avoid_: 将历史回答直接视为当前能力

**求助请求**：
成员为解决当前信息缺口，向指定成员提出的问题及获准发送的必要背景。请求允许对已有依据进行检索、计算与解释，其工作量受提供方授权限制。
_Avoid_: 开放式任务委托

**自动求助**：
工作 agent 为解决当前任务的信息缺口，在成员预先授权的群组、信息范围与资源额度内自行选择求助对象并提交请求。自动求助仍受发起方分享规则及提供方响应授权约束。

**会话求助授权**：
成员明确允许工作 agent 在当前工作会话内自动求助的授权，仍受其分享范围及资源额度约束。该授权不自动延续到其他会话，也不改变被求助成员的响应授权。

**成员收件箱**：
归属于成员、接收和保存发给该成员的求助请求及其处理状态的集合。请求的接收对象是成员，执行回答的 agent 可以在成员授权下更换。
_Avoid_: 将成员收件箱与某个 agent 的会话等同

**异步求助**：
求助提交后，发起方无需持续等待，接收方可以在之后具备处理条件时回答，发起方再按同一次请求读取结果。异步求助不要求双方的 Agent 同时在线。

**求助等待期限**：
求助者为自己发出的请求设定的有效等待时间。请求提交时确定截止时间，过期后不再自动处理等待请求。

**常驻响应 agent**：
成员授权用于持续接收并处理队友求助的 agent。其可回答的信息取决于当时可访问的授权资料，持续接收请求不意味着持续调用模型。

**本地响应器**：
成员授权用于接收队友求助、访问仅保留在本地的获准资料并提供回答的响应主体。资料访问和回答分享范围受成员授权约束。
_Avoid_: 将本地访问自动视为允许上传资料或对外提供全部内容

**本地查询范围**：
成员预设必须由本地响应器查询的资料来源或问题范围。符合该范围的求助使用本地资料，其余求助优先使用获准在线副本。

**工作 agent**：
成员在自己的日常工作中使用、随本人使用而启动或停止的 agent，也是成员发起求助与使用回答的主要产品入口。工作 agent 在成员授权下参与求助，其生命周期由成员及所用产品管理。

**响应模型**：
响应 agent 处理队友求助并生成回答所使用的模型。响应模型默认为云端模型，由成员从管理员配置的可用模型列表中选择，未设置时使用群组默认模型。响应模型的选择与定向求助的求助额度归属是两个独立概念。
_Avoid_: 将响应模型选择与求助者额度归属等同

**可用模型列表**：
管理员允许群组在线与本地响应器使用的云端模型集合。成员可以从中选择自己的响应模型，其调用账户由管理员配置。

**群组默认模型**：
成员未选择响应模型时，其响应器使用的模型，由管理员从可用模型列表中指定。

**回答策略**：
成员为自己的 agent 设定的资料选择、依据整理和回答表达规则。回答策略在成员授权的分享范围与资源额度内生效。

**采集规则**：
成员为收集个人资料设定的信息来源、内容范围和采集时机规则。允许采集某项内容不等于允许向群组分享该内容。

**整理规则**：
成员为个人资料设定的归类、摘要、关联和更新规则。整理形成的内容仍属于个人资料，向群组发布需要符合成员的分享范围。

**关注规则**：
成员为自己的响应 agent 设定的留言板关注主题、查看频率和参与资源额度规则。响应 agent 按规则自动查看相关留言并自主回答，发布留言不构成要求所有成员的 agent 参与的授权。

**留言板**：
群组内按保留规则保存问题、回答和主动分享内容的交流空间，供成员及其 agent 自主发现和参与。留言可以暂时无人回答。

**留言板问题等待期限**：
留言板问题接受自动回答的有效等待时间，提问者也可以因已解决或无需继续回答提前结束等待。等待结束不等于删除交流记录，记录继续按保留规则保存。

**通信监督**：
群组依据共同规则，对组内求助与回答中的违规或滥用行为进行检查和处理。能够查看通信记录的主体及其处理权限由群组规则规定。

**上下文审查**：
成员在工作过程中或工作结束后，检查自己的 Agent 获取及使用的其他成员的信息，判断这些信息与当前任务的关联和适用性。上下文审查不等于批准每次求助，也不等于通信监督。

**共享空间**：
按管理员及群组规则保存多人高频询问的可复用内容和全体成员必需内容，并维护其时效性与有效性的资料空间。已发布内容的保留与撤回独立于原始个人资料的保留与删除。
_Avoid_: 全体成员的个人资料库

**共享空间自动整理**：
依据群组规则，从留言板、已有共享内容和获准的定向求助记录中整理可复用内容并维护共享空间的过程。整理包括维护内容的时效性与有效性，及时剔除失效或错误内容；读取来源不等于获得向全组发布的权限。

**群组整理 Agent**：
群组配置并授权维护共享空间的 agent，负责从获准来源发现重复需求、整理有依据的解答，并维护已有共享内容。成员及其 agent 可以向其提交内容和纠正建议，发布内容仍须遵守内容提供者的分享范围。

**候选共享条目**：
准备收录到共享空间、由已有解答形成的可独立理解的内容及其来源、适用范围和时间信息。候选条目只有在符合收录条件且获得所需发布授权后，才能成为已发布共享内容。

**共享内容失效**：
已发布共享内容因到期、适用条件变化或有依据的错误纠正，不再适合作为当前检索与回答依据的状态。失效内容立即退出默认检索与自动回答依据，由群组整理 Agent 协调排查；确认有效或修订后有效则保留，否则删除条目。

**共享内容有效性待确认**：
已发布共享内容收到尚未证实的错误或失效反馈，由群组整理 Agent 协调内容提供方的 Agent 排查问题的临时状态。待确认内容不能作为确定结论使用，确认有效或修订后有效则保留，否则删除条目。

**共享条目删除**：
清理共享条目正文、专属依据副本及历史正文，只保留条目标识、删除时间和原因等最小处理记录。删除不改变原始交流的保留规则，也不清理其他有效条目仍使用的依据。

**必需内容通知**：
向全体成员告知群组必需内容已经发布或发生重要更新的信息。默认不要求确认已阅；管理员可以针对具体内容要求成员确认，通知送达、Agent 读取和成员确认分别记录。

**回答依据**：
用于支持回答的已有记录及其来源、版本、时间和适用背景。基于记录作出的推断应与记录本身区分。

**资源额度**：
成员为对外求助响应授权的资源使用上限，包括单次请求上限和累计使用上限。请求方及自定义策略不能自行提高提供方的额度。

**求助额度**：
成员向其他成员求助时允许消耗的模型 Token 额度。同一次定向求助中的在线与本地回答、分享检查和重试消耗归属于求助者，同时受被求助者授权的响应资源上限约束。

**留言板参与额度**：
成员为自己的响应 Agent 自动查看和回答留言板内容单独设置的模型 Token 消耗上限。参与消耗归属于该成员，并受群组总消耗上限约束。

**群组整理额度**：
管理员为共享空间整理与有效性排查单独设置的模型 Token 消耗上限，包括整理 Agent 协调提供方 Agent 排查时的消耗。消耗由群组承担，并受群组总消耗上限约束；提供方的响应资源上限仍然生效。

**群组消耗上限**：
群组对全部成员累计模型 Token 消耗设定的上限，由管理员管理，与每位成员的求助额度分别生效。该上限是群组内部的使用限制，不等同于模型服务账户的实际余额。
